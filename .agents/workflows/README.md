# ACON Workflows

Named repeatable patterns. Reference these in briefs or invoke by name.

| Workflow | Trigger phrase | What happens |
|----------|---------------|-------------|
| `scout-then-plan` | "Scout before planning" | Scout recon → Control Plane shapes plan |
| `implement-then-review` | "Implement, then review" | Worker implements → Reviewer checks → Worker applies fixes |
| `review-loop` | "Review loop, max N rounds" | Reviewer → Worker (fixes) → Reviewer, up to N times |
| `parallel-review` | "Parallel reviewers for X, Y, Z" | N Reviewers run concurrently, each with a single focus axis |
| `oracle-first` | "Get oracle's opinion first" | Oracle challenges the plan → Control Plane adjusts → dispatch |
| `council` | "/council" or "convene advisors" | 3 advisor oracles debate → Control Plane synthesizes |

See individual workflow files for full operating procedures.
