# Engineering Skills Suite

Core software engineering workflows and architectural problem-solving tools:

- **[SKILL.md](SKILL.md)**: Master engineering suite orchestrator.
- **[api-design](api-design/SKILL.md)**: RESTful modeling, RFC 7807 problem details, idempotency keys, cursor pagination, and HMAC webhooks.
- **[code-review](code-review/SKILL.md)**: Two-axis diff review (Standards + Spec).
- **[codebase-design](codebase-design/SKILL.md)**: Deep module design principles.
- **[diagnosing-bugs](diagnosing-bugs/SKILL.md)**: Fast-path direct fixes for obvious bugs; systematic feedback loop for elusive bugs.
- **[domain-modeling](domain-modeling/SKILL.md)**: Domain model and ADR documentation.
- **[frontend-conventions](frontend-conventions/SKILL.md)**: Modular file structure (≤300 lines), pragmatic logic separation, and zero reinvention of UI primitives.
- **[improve-codebase-architecture](improve-codebase-architecture/SKILL.md)**: Codebase deepening scanner.
- **[prototype](prototype/SKILL.md)**: Rapid throwaway HTML/UI prototypes.
- **[refactoring](refactoring/SKILL.md)**: Fowler refactoring catalog, Two-Hats rule, and strangler fig.
- **[setup-ts-deep-modules](setup-ts-deep-modules/SKILL.md)**: Deep module enforcement in TypeScript (opt-in).
- **[tdd](tdd/SKILL.md)**: Opt-in red-green-refactor TDD loop.
- **[to-spec](to-spec/SKILL.md)**: Conversation-to-spec extraction (opt-in).
- **[wizard](wizard/SKILL.md)**: Interactive CLI setup wizard for humans.
- **[zero-downtime-migrations](zero-downtime-migrations/SKILL.md)**: 5-phase Expand/Contract pattern and online index creation (high-traffic production only).
