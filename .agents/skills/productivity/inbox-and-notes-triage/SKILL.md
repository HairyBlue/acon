# Inbox Triage, Reply Drafter & Second-Brain Notes

## Use this when

The user asks to triage emails/messages, draft a reply or memo, or organize meeting notes, articles, and bookmarks into local Markdown.

## Process

1. **Inbox Triage:** Classify unread or pasted messages into **Reply Needed Today**, **Follow-Up / Waiting On**, and **Ignore / Newsletter**.
2. **Anti-AI-Slop Reply Drafting:** Draft concise, natural, human-sounding replies that answer the sender's actual question directly without corporate filler.
3. **Second-Brain Note Curation:** Distill raw notes, meeting transcripts, or articles into structured Markdown with **Summary**, **Key Facts**, **Decisions**, **Action Items**, and **Source Links**. Confirm the target local Markdown path before writing.

## Output

Use: Triaged Message Table, Draft Replies (for review), or Structured Markdown Note + Confirmed Local Path.

## Guardrails

Never send an email or message automatically without explicit user approval. Never overwrite existing local note files without asking first.
